# Banakar Bistro Menu

منوی دیجیتال و سیستم مدیریت سفارش و رزرو برای کافه باناکار؛ ساخته‌شده با Next.js، TypeScript و Supabase.

## معرفی

Banakar Bistro Menu یک تجربه منوی سریع و واکنش‌گرا برای مشتریان و یک پنل مدیریت برای ادمین کافه است. مشتری می‌تواند محصولات را ببیند، میز خود را انتخاب کند، سفارش ثبت کند و برای میز رزرو بفرستد. ادمین نیز محصولات، سفارش‌ها و رزروها را از یک پنل اختصاصی مدیریت می‌کند.

## قابلیت‌ها

- منوی دسته‌بندی‌شده با جست‌وجو و صفحه جزئیات محصول
- نمایش موجودی، ناموجودی، پیشنهاد ویژه و آرشیو محصولات
- پشتیبانی از variant برای محصولاتی مانند نوشیدنی‌ها
- سبد خرید با انتخاب میز و ثبت سفارش بدون پرداخت آنلاین
- فرم رزرو میز با تاریخ شمسی و ساعت رزرو
- پنل مدیریت RTL با سایدبار اختصاصی
- مدیریت سریع محصولات در پنل ادمین
- مدیریت وضعیت سفارش‌ها و رزروها
- تقویم ماهانه رزروها با نمایش تعداد رزرو هر روز
- افزودن رزرو تلفنی توسط ادمین
- اعلان داخل پنل، صدای اعلان و اعلان سیستم‌عامل برای سفارش و رزرو جدید
- استفاده از `next/image` برای تصاویر محصولات و صفحات اصلی
- احراز هویت ادمین با Supabase Auth
- فعال‌سازی RLS برای جدول‌های اصلی Supabase

## فناوری‌ها

- Next.js 16 با App Router
- React 19
- TypeScript
- Tailwind CSS
- Supabase Auth, Database و Realtime
- `react-multi-date-picker` برای تقویم شمسی

## اجرای پروژه

پیش‌نیازها:

- Node.js 20 یا بالاتر
- یک پروژه Supabase

نصب وابستگی‌ها:

```bash
npm install
```

اجرای محیط توسعه:

```bash
npm run dev
```

پروژه در آدرس زیر در دسترس خواهد بود:

```text
http://localhost:3000
```

ساخت نسخه Production:

```bash
npm run build
npm run start
```

## متغیرهای محیطی

فایل `.env.local` را در ریشه پروژه بساز:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
SUPABASE_SECRET_KEY=your_supabase_secret_key
```

کلید Secret فقط باید در سمت سرور استفاده شود و نباید در کد Client یا Git قرار بگیرد.

## ساختار مهم پروژه

```text
app/
├── admin/              پنل مدیریت و صفحات ادمین
├── api/                API سفارش‌ها و رزروها
├── menu/               منو و صفحه جزئیات محصولات
└── reserve/            صفحه رزرو میز

components/
├── admin/              کامپوننت‌های پنل مدیریت
├── menu-card.tsx       کارت محصول
├── cart-drawer.tsx     سبد خرید
└── booking-form.tsx    فرم رزرو

lib/
├── menu.ts             مدل‌ها و داده‌های پایه منو
├── tables.ts            فهرست میزها
└── supabase/            کلاینت‌ها و توابع دسترسی به Supabase
```

## Supabase

جدول‌های اصلی پروژه:

- `products`
- `product_variants`
- `orders`
- `order_items`
- `reservations`

برای جدول‌های اصلی RLS فعال است. کاربران عمومی فقط اجازه ثبت سفارش و رزرو دارند و عملیات مدیریتی به کاربران احراز‌هویت‌شده محدود شده است.

## اعلان و پاک‌سازی سفارش‌ها

اعلان‌های سفارش و رزرو از Realtime Supabase استفاده می‌کنند. برای حذف خودکار سفارش‌های روز قبل نیز می‌توان از `pg_cron` در Supabase استفاده کرد. زمان‌بندی فعلی پروژه برای ساعت ۰۲:۰۰ بامداد به وقت تهران در نظر گرفته شده است.
