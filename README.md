# ☕ Cafe & Lounge — Digital Menu & Ordering Experience

یک وب‌اپلیکیشن مینیمال، مدرن و با سبک طراحی ژورنالی (Editorial Design) برای کافه‌ها و رستوران‌های لوکس که با **Next.js (App Router)**، **TypeScript** و **Tailwind CSS** توسعه یافته است.

---

## ✨ ویژگی‌های برجسته (Key Features)

- ⚡ **معماری فوق سریع (SSG & Dynamic Routing):** رندر استاتیک صفحات با `generateStaticParams` برای بالاترین سرعت لود و بهینه‌سازی موتورهای جستجو (SEO).
- 🎨 **تایپوگرافی و طراحی اختصاصی (Editorial & Luxury Aesthetic):**
  - استفاده از Fluid Typography با ترکیب CSS `clamp()` برای نمایش خیره‌کننده در ابعاد مختلف صفحه.
  - پالت رنگی گرم و مینیمال با ته‌رنگ‌های متالیک (Copper/Ink).
- 🛒 **سبد خرید تعاملی (Off-canvas Cart Drawer):**
  - مدیریت سراسری وضعیت با React Context API.
  - ذخیره‌سازی و پایداری سفارش‌ها (Persistence).
  - تفکیک وضعیت‌های کشو (خالی، پر، و دمو سفارش ثبت‌شده).
- 🧩 **کامپوننت‌های کنترل‌شده و بومی:**
  - سیستم انتخاب زمان (`TimeField`) با چیدمان RTL و تبدیل خودکار ارقام به اعداد فارسی.
  - فیلترینگ و ریتم بصری خودکار در ویترین اقلام منو (`useMemo`).
- 📱 **کاملاً واکنش‌گرا (Responsive & Mobile-first):** چیدمان منعطف با Flexbox و Grid برای بهترین تجربه کاربری در موبایل، تبلت و دسکتاپ.

---

## 🛠 تکنولوژی‌های استفاده‌شده (Tech Stack)

- **فریم‌ورک:** [Next.js](https://nextjs.org/) (App Router)
- **زبان:** [TypeScript](https://www.typescriptlang.org/)
- **استایل‌دهی:** [Tailwind CSS](https://tailwindcss.com/)
- **آیکون‌ها:** Custom SVG Icon System
- **مدیریت وضعیت:** React Context API & Custom Hooks
